## Why React Tutor?

Most React tutorials are videos you can only watch, or text you can only read. **React Tutor is an interactive React course
for beginners** that combines both. You learn by doing:

- 🎙️ **Narrated, interactive coding lessons.** The teacher's code types itself into a real code editor while a voice
  explains each line. Press pause and the editor is yours: change the code and see the result right away.
- 🌐 **A live preview next to the code.** Every lesson runs in a built-in mini browser, so you see your web page change
  as you type.
- 🤖 **Kit, a personal AI coding tutor.** Ask questions in plain English, by typing or by talking. Kit can see your code
  and explains your mistakes without just handing you the answer.
- ✨ **Learn anything.** Type a topic ("how do forms work?", "make a to-do list") and Kit writes a whole new lesson
  with a practice exercise, just for you.
- 🔁 **Change this lesson.** Too fast? Say "explain that again more slowly" or "use a pet shop example" and the lesson
  adapts while you watch.
- 🧩 **Practice exercises and quizzes** after every lesson, with automatic checks that tell you what to fix.
- 💡 **Smart autocomplete** in the editor for HTML tags, React hooks and common JavaScript, so beginners type less.
- 🔒 **Private and offline-friendly.** The lessons, the voice and the speech-to-text all run on your own computer.

## 📚 What you will learn

About **140 bite-sized lessons in 20 modules**, from "what is code?" to building a full React app. No prior coding
experience needed, and nothing is locked: jump to any lesson you like.

| Part                   | Topics                                                                                                  |
| ---------------------- | ------------------------------------------------------------------------------------------------------- |
| **JavaScript basics**  | variables, values, functions, if/else decisions, arrays, objects, loops, the DOM and events, modules    |
| **React fundamentals** | JSX, components, props, rendering lists, conditional rendering, state with `useState`, forms            |
| **Thinking in React**  | splitting a UI into components, effects and fetching data with `useEffect`, refs, context, custom hooks |
| **React Router**       | pages and links, URL parameters, nested routes, search params, loading data                             |
| **Capstone project**   | build a complete multi-page React app from scratch                                                      |

## 🚀 Install it in 2 minutes

You do **not** need to install Node.js, a code editor or anything else. Just download the app.

### Windows (10 or 11)

1. Go to the [**latest release**](https://github.com/YOUR-GITHUB-USERNAME/react-tutor/releases/latest).
2. Under **Assets**, download the file ending in **`-setup.exe`**.
3. Double-click it and follow the installer.
4. If Windows shows **"Windows protected your PC"**, click **More info**, then **Run anyway**.
   (This appears because the app is new and not yet signed. It is safe.)
5. Open **React Tutor** from the Start menu.

### Linux

1. Go to the [**latest release**](https://github.com/YOUR-GITHUB-USERNAME/react-tutor/releases/latest).
2. Pick one:
    - **Ubuntu, Debian, Linux Mint:** download the **`.deb`** file and double-click it to install.
    - **Fedora, openSUSE:** download the **`.rpm`** file and double-click it to install.
    - **Any other Linux:** download the **`.AppImage`** file. Right-click it, open **Properties → Permissions**, tick
      **Allow executing file as program**, then double-click it.
3. Open **React Tutor** from your applications menu.

### First launch: turn on the voice (optional, one time)

The app can read lessons aloud with a natural-sounding voice that runs on your own computer.

1. Open **Settings → Voice & microphone**.
2. Click **Set up**. The app picks the best voice for your computer and downloads it
   (about 1 GB, or about 5 GB if you have an NVIDIA graphics card).
3. Wait for it to finish. That's it, and you only do this once.

Until then, lessons use your computer's built-in voice, so you can start learning right away.

### Connect Kit, your AI tutor (optional)

Lessons, exercises and quizzes work without AI. To chat with Kit or create your own lessons, open **Settings** and
choose one:

- **Sign in with ChatGPT** if you have a ChatGPT account. Easiest option.
- **Paste an API key** from an AI provider such as OpenAI, Anthropic, OpenRouter or Groq (60+ providers are listed),
  or point it at a model running on your own computer.

Then pick a model from the list and you are ready.

## ❓ Frequently asked questions

**Is React Tutor free?**
Yes. The app and all of its lessons are free. Kit uses your own AI account or API key, so any AI usage is billed by
that provider, not by us.

**Do I need to know how to code?**
No. The course starts from zero and explains every new idea in plain language before you use it.

**Does it work offline?**
Yes. Lessons, exercises, quizzes, the voice and speech-to-text all work offline once set up. Only Kit, the AI tutor,
needs an internet connection (unless you use a local AI model).

**Is my data private?**
Your progress and code are stored on your computer. Once the voice is set up, what you say into the microphone is
turned into text on your computer, not in the cloud. Sign-in tokens and API keys are kept in your operating system's secure password store.

**Is macOS supported?**
Not as a download yet. Developers can build it from source (see below).

**Why learn React?**
React is the most popular way to build websites and web apps today. Knowing JavaScript and React is one of the most
in-demand skills for front-end and full-stack web developer jobs.

## 🛠️ For developers

<details>
<summary>Build from source, run tests, write lessons</summary>

Requirements: [Node.js](https://nodejs.org) 22+, [Rust](https://rustup.rs), and the
[Tauri prerequisites](https://tauri.app/start/prerequisites/) for your OS.

```bash
npm install
npm run tauri dev      # run the app with hot reload
npm test               # timeline, providers, and a validator that runs every lesson's code and tests
npm run tauri build    # build installers into src-tauri/target/release/bundle
```

Project layout:

- `src/course/modules/` – the course: 20 modules of lessons, practice exercises and quizzes. See
  [docs/AUTHORING.md](docs/AUTHORING.md) to write lessons.
- `src/player/` – the lesson player: narration timeline, CodeMirror editor, challenges, captions.
- `scripts/sandbox/` – the preview sandbox (Sucrase + bundled React, ReactDOM and React Router, offline fake `/api/*`).
- `src/ai/`, `src/Tutor.tsx` – Kit: OpenAI-compatible APIs, Anthropic, Sign in with ChatGPT, Claude Code and Codex CLIs.
- `tts/server.py`, `src/narration.ts` – narration (Kitten TTS) and speech-to-text (faster-whisper) in a private
  [uv](https://docs.astral.sh/uv/)-managed Python environment.

Releases: publish a GitHub release and the [release workflow](.github/workflows/release.yml) builds the Windows and
Linux installers and attaches them to it. The app version comes from `package.json` (also update
`src-tauri/Cargo.toml`).

</details>
